# CREATIVA

## Prototype CREATIVA

Prototype ini merupakan gambaran awal dari konsep **CREATIVA**, sebuah ekosistem digital yang dirancang untuk membantu talenta kreatif berkembang dari pemetaan kompetensi, pembentukan tim, hingga pengembangan venture.

Prototype ini **bukan merupakan bentuk final dari aplikasi CREATIVA**, melainkan visualisasi interaktif untuk menggambarkan bagaimana konsep dan alur kerja CREATIVA dapat diterapkan dalam sebuah platform digital.

Silakan mencoba prototype melalui halaman utama dan mengikuti alur yang tersedia.
